## Правила разделения intents

Primary означает редакционное назначение, а не гарантию выбранного поисковиком URL. Все полезные уроки остаются индексируемыми с собственным canonical. Не ставим canonical урока на reference: это разные материалы.

- Общая механика binary search → reference. Точный поиск с закрытыми границами → урок инварианта; первая граница → boundaries; монотонная проверка ответа → on-answer.
- Общий метод two pointers → reference. Поиск пары в отсортированном массиве → opposite-two-pointers. Fast/slow упомянут как отдельная схема, не доказан тем же аргументом суммы.
- Общий алгоритмический sliding window → reference. Уникальная подстрока → variable-sliding-window; фиксированная длина → fixed-sliding-window.
- Бинарное дерево поиска (480) — не binary search по массиву. TCP (33), обычные окна/закат, скользящее среднее (70) — не повод расширять landing окна.
- Широкий Big O содержит big o clock 2 087, big s o 1 284, big o live 624, big o c 573, little big o 538. Нельзя приписывать 7 470 алгоритмам.
- Фразы «читать» (567), «1 алгоритм…» (831), «структуры и алгоритмы обработки данных» (346) не автоматически означают интерактивный курс. Отдельные страницы не создаём.

Новых публичных routes: **0**. Контроль фактической cannibalization в 008: query × page за одинаковые интервалы, показы/клики по нескольким URL, затем проверка их intent. До данных корректно утверждать только, что одинаковые редакционные targets устранены.
