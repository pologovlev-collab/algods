# Графы, списки смежности и сетки

Для неориентированных рёбер `(0,1)` и `(0,2)` списки равны `[[1,2],[0],[0]]`: каждое ребро записано дважды, по одному разу у каждого конца.

<!-- algods:problem-shape -->
## Как представить соседей каждой вершины?

По списку неориентированных рёбер построить соседей каждой из n вершин.

<!-- algods:brute-force -->
## Матрица смежности для любого графа

Создать матрицу n×n и отметить каждую связь.

<!-- algods:bottleneck -->
## Почему n² ячеек расточительны для редких рёбер?

Матрица тратит O(n²) памяти даже для разреженного графа с O(n) рёбрами.

<!-- algods:key-observation -->
## Для обхода достаточно хранить существующих соседей

Для обходов нужны только реально существующие соседи; каждое неориентированное ребро добавляется в два списка.

<!-- algods:invariant-state -->
## Что содержит adjacency после очередного ребра?

После обработки k рёбер adjacency[v] содержит ровно соседей v среди этих k рёбер.

<!-- algods:algorithm -->
## Добавляем оба направления неориентированного ребра

Создать n пустых списков. Для ребра (u,v) проверить границы, добавить v к u и u к v. Для ориентированного добавить только направление u→v.

<!-- algods:implementation -->
## Список смежности на C++17 и Python 3

### C++17

```cpp
#include <cassert>
#include <stdexcept>
#include <utility>
#include <vector>
using namespace std;

vector<vector<int>> buildGraph(
    int vertexCount,
    const vector<pair<int, int>>& edges
) {
    if (vertexCount < 0) throw invalid_argument("negative vertex count");
    vector<vector<int>> adjacency(vertexCount);
    for (auto [from, to] : edges) {
        if (from < 0 || from >= vertexCount || to < 0 || to >= vertexCount) {
            throw out_of_range("vertex index");
        }
        adjacency[from].push_back(to);
        adjacency[to].push_back(from);
    }
    return adjacency;
}

int main() {
    auto graph = buildGraph(3, {{0, 1}, {0, 2}});
    assert((graph[0] == vector<int>{1, 2}));
    assert((graph[1] == vector<int>{0}));
    assert(graph[2] == vector<int>{0});
}
```

### Python 3

```python
def build_graph(
    vertex_count: int,
    edges: list[tuple[int, int]],
) -> list[list[int]]:
    if vertex_count < 0:
        raise ValueError("negative vertex count")
    adjacency = [[] for _ in range(vertex_count)]
    for start, end in edges:
        if not (0 <= start < vertex_count and 0 <= end < vertex_count):
            raise IndexError("vertex index")
        adjacency[start].append(end)
        adjacency[end].append(start)
    return adjacency


graph = build_graph(3, [(0, 1), (0, 2)])
assert graph == [[1, 2], [0], [0]]
```

<!-- algods:complexity -->
## Память O(n + m) и две записи на ребро

O(n+m) памяти и O(n+m) построения для n вершин и m рёбер: сначала создаются n пустых списков, затем добавляются записи рёбер. Полный обход всех списков читает 2m записей в неориентированном графе.

## Как распознать граф в отношениях и переходах?

Сущности соединены произвольными отношениями; из каждого состояния нужно перечислять доступные переходы.

<!-- algods:when-not-to-use -->
## Когда матрица смежности действительно уместна?

Матрица смежности уместна для плотного графа или частых O(1)-проверок конкретного ребра.

Вопрос: почему сумма длин списков неориентированного графа равна 2m? Ответ: каждое ребро записано у обоих концов.
