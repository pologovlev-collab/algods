# AlgoDS

AlgoDS — статический русскоязычный курс по алгоритмам, структурам данных и решению
задач на технических собеседованиях. Основной маршрут состоит из 54 уроков в 21 этапе;
примеры для C++17 и Python 3 равноправны.

## Локальная разработка

Рекомендуются Node.js 24 и npm 11; допустимые версии зафиксированы в `package.json`.

```bash
npm ci
npm run dev
```

Основные проверки:

```bash
npm run check
npm run lint
npm test
npm run validate:content
npm run validate:examples
npm run build
npm run validate:links
npm run verify
```

`verify` также запускает `validate:examples`: команда извлекает все парные примеры из основных уроков, компилирует C++ с
`-std=c++17` и запускает обе языковые версии. Для команды нужны `g++` и `python` в
`PATH`.

## Архитектура

- `src/content/lessons/` — учебные тексты и проверяемые метаданные;
- `src/data/` — этапы, паттерны, справочные темы и проверенные наборы практики;
- `src/components/` — переиспользуемые элементы курса, карты, справочника, поиска и прогресса;
- `src/lib/` — чистая логика прогресса, графа зависимостей, справочника, поиска и валидации;
- `src/pages/` — статически генерируемые маршруты Astro;
- `scripts/` — проверки контента, примеров и итоговых ссылок;
- `tests/` — модульные и контрактные тесты.

Контент отделён от интерфейса: новый основной урок добавляется Markdown-файлом с JSON
frontmatter по схеме `src/content.config.ts`. Его идентификатор должен быть уникальным,
а все зависимости — ссылаться только на более ранние уроки без циклов.

Карта знаний строится из реальных зависимостей уроков, справочник генерирует отдельные
статические маршруты, а глобальный поиск собирает типизированный индекс курса, справочника
и практики во время сборки без серверной части.

## Локальный прогресс

Аккаунт и сервер не нужны. Язык кода, уроки, статусы задач, закладки и календарь
хранятся в браузере в версии схемы `algods:progress:v2`. Интерфейс позволяет выгрузить
JSON, импортировать его и сбросить только данные AlgoDS после подтверждения.

## Публикация

`astro.config.mjs` фиксирует канонический домен `https://algods.ru` и статическую сборку.
Workflow `.github/workflows/deploy.yml` проверяет и публикует сайт в GitHub Pages только
из `main` или при ручном запуске; feature-ветки в production не отправляются.
